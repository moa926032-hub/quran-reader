# quran-reader
أفضل موقع لي قُراء القرآن الكريم و محبين التفسير و إستخدام نبرات أعظم القُراء حيث يتكون الموقع من... 
​🛠️ الميزات الأساسية وكيفية تنفيذها:
​تقليب الصفحات (التالي/السابق)
​زر التفسير البسيط:
​عند الضغط عليه، هيبعت طلب للـ API يجيب "التفسير الميسر" الخاص بالآيات اللي في الصفحة دي ويعرضها في نافذة منبثقة (Modal) أو في جزء أسفل الصفحة بشكل منظم.
​البحث برقم الصفحة:
​صندوق إدخال (Input) بسيط، تكتب فيه الرقم، وتعمل عليه Validation إنه ما يقلش عن 1 وما يزدش عن 604، وأول ما تدوس Enter، الـ currentPage يتغير للقيمة دي ويجيب الصفحة فوراً.
​البحث باسم السورة:
​قائمة منسدلة (Drop-down menu) أو صندوق بحث ذكي (Autocomplete). أول ما تكتب "الدخان"، الكود هيدور في لستة السور اللي عندك ويجيب رقم أول صفحة للسورة دي (مثلاً الدخان تبدأ من صفحة 496)، ويقوم الـ Web App قالب عليها تلقائيًا.
​وضع ملء الشاشة (Full Screen Mode):
​
​💡 
​1. حفظ مكان القراءة تلقائياً (علامة الحفظ - Bookmark)
​مش منطقي المستخدم كل ما يقفل الموقع ويرجع، يدور هو كان واقف في صفحة كام.
​2. الوضع الليلي (Dark Mode) والوضع الدافئ (Sepia)
​القراءة بالليل محتاجة ألوان مريحة للعين.
الـ​3. الاستماع للقراءة (Audio Player)
​ضيف زرار "تشغيل الصوت" في الصفحة.
​الـ API يقدر يمدك بملفات صوتية لأشهر القراء (المنشاوي، الحصري، العفاسي...). لما يدوس تشغيل، يشتغل صوت الشيخ وهو بيقراء تقدر العفاسيء ء.
​4. البحث بالكلمات والآيات 
​5. الاستجابة للموبايل (Responsive Design) والتنقل باللمس (Swipe)
​بما إن أغلب الناس هتقرأ من الموبايل، لازم التصميم يكون Responsive بنسبة 100% إحتراف
