🌙 عن المشروع

Quran Reader هو مشروع ويب إسلامي يهدف إلى توفير تجربة مريحة ومميزة لقراءة القرآن الكريم، مع إمكانية الوصول إلى التفسير الميسر والاستماع إلى تلاوات أشهر القراء، في واجهة عصرية تناسب الهواتف وأجهزة الكمبيوتر.

نسعى إلى الجمع بين سهولة القراءة وجمال التصميم وسرعة الوصول إلى الآيات والتفسير والتلاوات القرآنية.

✨ المميزات

- 📖 تصفح صفحات المصحف — الانتقال بين الصفحات التالية والسابقة
- 📚 التفسير الميسر — عرض تفسير الآيات الخاصة بالصفحة في نافذة منظمة
- 🔢 البحث برقم الصفحة — الانتقال مباشرة إلى أي صفحة من صفحات المصحف من 1 إلى 604
- 🕌 البحث باسم السورة — الوصول إلى السورة المطلوبة والانتقال إلى صفحة بدايتها
- ⛶ وضع ملء الشاشة — تجربة قراءة أكثر تركيزًا
- 🔖 حفظ موضع القراءة — الاحتفاظ بآخر صفحة وصلت إليها للمتابعة لاحقًا
- 🌙 الوضع الليلي — واجهة مريحة للقراءة في الإضاءة المنخفضة
- 📜 الوضع الدافئ Sepia — ألوان هادئة مناسبة للقراءة المطولة
- 🎧 الاستماع إلى التلاوات — إمكانية الاستماع إلى أصوات كبار القراء مثل المنشاوي والحصري والعفاسي حسب القراء والتلاوات المتاحة عبر واجهة البرمجة المستخدمة
- 🔍 البحث عن الكلمات والآيات — الوصول إلى الآيات المطلوبة بسهولة
- 📱 تصميم متجاوب — تجربة مناسبة للموبايل والتابلت والكمبيوتر
- 👆 التنقل باللمس — تقليب الصفحات بالسحب على الشاشات الداعمة

🛠️ التقنيات

يعتمد تنفيذ المشروع على تقنيات الويب الحديثة وواجهات برمجة التطبيقات (APIs) لتوفير بيانات القرآن الكريم والتفسير والتلاوات الصوتية.

- HTML5 — بناء هيكل صفحات الموقع
- CSS3 — تصميم الواجهة وتنسيقها
- JavaScript — تنفيذ التفاعلات والتنقل والبحث
- Quran API — جلب بيانات القرآن الكريم والتفسير والتلاوات بحسب الخدمة المستخدمة

«ملاحظة: التقنيات وواجهات البرمجة المذكورة تمثل الهيكل المقترح للمشروع، وقد تختلف حسب التنفيذ الفعلي.»

🎯 هدف المشروع

تقديم تجربة قرآنية سهلة ومريحة تساعد محبي القرآن الكريم على القراءة والتدبر والوصول إلى التفسير والاستماع إلى التلاوات، مع الاهتمام بسهولة الاستخدام على مختلف الأجهزة.

نسأل الله أن يجعل هذا العمل خالصًا لوجهه الكريم وأن ينفع به كل من يقرأ كتابه ويتدبر آياته 🤍
